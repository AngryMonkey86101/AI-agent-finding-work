# AI-агент поиска работы

Агент ищет вакансии на hh.ru и SuperJob, пишет сопроводительные письма через DeepSeek и присылает их в Telegram.
Вы откликаетесь в один клик (кнопки «Открыть на hh.ru» и «Скопировать письмо»), а если в вакансии
указан email, агент по вашей кнопке отправит письмо с резюме туда. Каждый вечер приходит отчёт.

hh.ru закрыл API для соискателей 15.12.2025, поэтому автоматической отправки откликов на hh.ru нет.

- [x] Шаг 4. Вечерний отчёт в Telegram в выбранное время (по умолчанию 18:00), команда /report

Если hh.ru отвечает 403 `forbidden`, он не пускает IP вашего сервера (часто так бывает с зарубежными VPS). Укажите в панели «Прокси для hh.ru» с российским IP и нажмите «Проверить доступ к hh.ru» на странице вакансий. Через прокси идут только запросы к hh.ru.

## Запуск на VPS

```bash
git clone https://github.com/AngryMonkey86101/AI-agent-finding-work.git
cd AI-agent-finding-work
cp .env.example .env        # задайте ADMIN_PASSWORD
docker compose up -d --build
```

Панель слушает `127.0.0.1:8000`, то есть снаружи её не видно. Открыть её можно двумя способами:

- SSH-туннель: `ssh -L 8000:localhost:8000 user@ваш-vps`, затем в браузере http://localhost:8000
- nginx с HTTPS (Let's Encrypt), проксирующий на `127.0.0.1:8000`

Вход по логину и паролю из `.env`. Сначала заполните настройки и загрузите резюме, затем на странице
«Найденные вакансии» нажмите «Запустить поиск сейчас», чтобы проверить, что всё работает.

Docker поднимает три сервиса: `panel` (веб-панель), `worker` (ищет вакансии каждые N минут из настроек)
и `bot` (Telegram-бот).

### Telegram

1. Создайте бота у @BotFather и вставьте токен в панель.
2. Напишите своему боту `/start`, он ответит вашим chat ID. Впишите его в панель.
3. Подходящие вакансии будут приходить карточками: письмо в рамке копируется нажатием,
   кнопки «Открыть», «✅ Отправил», «⏭ Пропустить», «✏️ Изменить письмо» и «📧 На email»
   (если в вакансии есть почта и в панели включены отклики по email). Перед отправкой email бот
   спросит подтверждение. Команда `/status` показывает сводку за сегодня.
4. Каждый день во время из панели (по умолчанию 18:00 по вашему часовому поясу) бот присылает
   отчёт: сколько вакансий найдено, куда вы откликнулись, что ушло на email и что ждёт решения.
   Получить отчёт сразу: `/report`.
Логи воркера: `docker compose logs -f worker`. Разовый проход: `docker compose run --rm worker python -m app.worker --once`. Настройки и резюме хранятся в папке `data/` (SQLite).
